# CONNECTX

This repository contains the CONNECTX project, including a Next.js frontend in `connectx/` and a backend API in `backend/`.

## Structure

- `connectx/` - frontend application built with Next.js
- `backend/` - server application with Node.js and Prisma
- `CONNECTX_Project_Documentation.md` - project documentation summary

## Setup

### Frontend

```bash
cd connectx
npm install
npm run dev
```

### Backend

```bash
cd backend
npm install
npm run dev
```

## Deployment

- Push this repository to GitHub
- Connect the GitHub repo to Vercel and deploy the `connectx/` app
- Use Vercel environment variables for backend configuration if needed
